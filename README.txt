# My Mobile App Demo (Python)

A beginner-friendly mobile-style application built with Python and Streamlit.

## Features
- Home screen
- Login form (demo only; no authentication or password storage)
- Student profile screen
- Simple screen navigation
- Responsive, mobile-friendly layout

## Requirements
- Python 3.9 or newer
- Internet connection for the first installation

## Run on Windows
1. Extract this ZIP file.
2. Open the extracted folder.
3. Click the folder address bar, type `cmd`, and press Enter.
4. Run:

   ```bash
   python -m pip install -r requirements.txt
   streamlit run app.py
   ```

5. The app opens in your browser. To view a phone-sized layout, press `F12` in Chrome and select the device toolbar.

## Important
This is a Python web app that looks like a mobile app and runs in a browser. It is not an APK or a native Android/iOS app.
